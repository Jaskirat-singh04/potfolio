Guardrailed Enterprise LLM Gateway

A governed LLM access layer routing every request through policy checks, with role and attribute-based access control so different teams get different capabilities from the same system.

Lesson Blanket guardrails frustrated legitimate power users and still missed edge cases. Moving to attribute-based rules per user role cut false blocks sharply while tightening the actual risk surface.
